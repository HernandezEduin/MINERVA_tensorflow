# Manuscript Overview

This folder contains the current unpublished manuscript:
- `Theseus in the Graph.pdf`

## What The Paper Covers

The manuscript presents an enhanced MINERVA-style framework for multi-hop
knowledge graph question answering (KGQA) from natural language questions.
It focuses on how an RL agent can navigate a graph conditioned on question
representations to reach correct answer entities.

Main themes include:
- Natural-language question encoding with transformer-based embeddings.
- Multi-hop path reasoning with graph navigation policies.
- Training and evaluation settings for realistic KGQA benchmarks.
- Diagnostic analysis beyond final accuracy (e.g., path behavior and faithfulness).

In short, the paper ties together model design, training procedure, and
reasoning-quality evaluation for interpretable multi-hop KGQA.
